## Быстрый старт

```text
/probiv id123456                          → пробить по айди вк / пробив id вк
/probiv 123456                            → тоже
/probiv https://vk.com/id123456           → пробить по ссылке вк
/probiv https://vk.com/durov              → пробив по юзу вк (durov = юз)
/probiv durov                             → тоже
/probiv @durov                            → тоже
/probiv https://vk.com/id123456?from=search → пробив через страницу вк — сработает
```

Бот сам определит формат — ID, ссылка, юз.

## ID vs ссылка vs юз — в чем разница

- **ID** — `id123456` (цифровой)
- **Юз** — `durov` (короткое имя после `vk.com/`)
- **Ссылка** — `https://vk.com/durov` или `https://vk.com/id123456` (полный URL)

Для бота разницы нет — кидай любой формат.
