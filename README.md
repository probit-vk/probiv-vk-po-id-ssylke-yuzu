**[Пробив ВК](https://github.com/probit-vk)** — экосистема поиска информации о профиле по VK ID, username и ссылке. Этот раздел посвящён идентификации страницы и сопоставлению её с записями собственного индекса.

## Какие данные можно отправить

```text
123456
id123456
https://vk.com/id123456
username
https://vk.com/username
```

Числовой VK ID — самый устойчивый идентификатор: он сохраняется при смене имени и короткого адреса. Если пользователь отправляет ссылку с username, система сначала определяет соответствующий ID, а затем выполняет поиск связанных записей.

## Как проходит поиск

1. Входная строка очищается от лишних параметров ссылки.
2. Система распознаёт ID, username или URL.
3. Короткий адрес преобразуется в числовой идентификатор.
4. VK ID сопоставляется с собственным индексом.
5. Найденные текущие и исторические записи объединяются в отчёт.

Такой подход помогает не потерять связь с профилем после изменения username. Если старый и новый адрес ранее относились к одному ID, они могут появиться в истории одной страницы.

## Поиск по закрытой странице

Закрытый профиль также можно определить по ссылке или идентификатору. Ограничение текущей видимости страницы не удаляет сведения, уже сохранённые в независимом индексе. В результате могут присутствовать прежние имена, username, аватары, связанные упоминания и ранее проиндексированные контакты, если такие записи имеются.

Полнота результата зависит от покрытия базы: отсутствие поля означает, что для него не найдено подтверждённой записи.

## Примеры

| Известное значение | Действие системы |
|---|---|
| `id123456` | Поиск напрямую по VK ID |
| `vk.com/id123456` | Извлечение ID из ссылки |
| `vk.com/username` | Определение ID по короткому адресу |
| `username` | Нормализация и поиск соответствующего профиля |

Запустить проверку можно через [Telegram-бота](https://bot-probiv.org/). Общее описание продукта находится в [основном репозитории](https://github.com/probit-vk/probiv-vk), а отдельный сценарий проверки страницы — в разделе [поиск по профилю и аккаунту](https://github.com/probit-vk/probiv-vk-profil-stranica-akkaunt).
